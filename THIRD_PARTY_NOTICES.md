reconstructed over a pinned upstream Android project and packages or invokes
multiple third-party runtimes. Those projects retain their own copyrights,
licenses, notices and trademarks.

This document is a compliance index, not a replacement for the original
license texts. The SBOM and the exact source/runtime revisions used for a
specific build are the authoritative inventory for that build.

## FFmpeg

FFmpeg states that most of the project is LGPL v2.1 or later, while optional GPL
components and external libraries can change the licensing requirements of a
particular compiled binary. Consequently, InSave must record the provenance and
configuration of the exact FFmpeg binaries packaged in each Heavy release.

- Official legal/licensing guidance: https://ffmpeg.org/legal.html
- Project license overview: https://ffmpeg.org/doxygen/trunk/md_LICENSE.html

Do not describe a packaged FFmpeg binary as “LGPL-only” unless the build
configuration and included external libraries have been verified.

## Release compliance rule

Before publishing an APK/AAB as an official release:

1. generate the SBOM from the exact reconstructed source;
2. verify the exact checksums/revisions of packaged runtimes;
3. collect the license/notices for the exact runtime forms being shipped;
4. ensure GPL corresponding source is available for GPL-covered conveyed work;
5. retain required copyright and attribution notices;
6. record any FFmpeg build/configuration licensing decision;
7. do not remove third-party notices during branding or minification.

If the packaged runtime inventory changes, this file and the release evidence
must be reviewed again.
