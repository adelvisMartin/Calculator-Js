# Code of Conduct

InSave welcomes technical discussion, testing, bug reports and contributions
that improve the project.

Participants are expected to:

- discuss code, evidence and behavior rather than attack people;
- avoid harassment, threats, discrimination or targeted abuse;
- respect privacy and never publish another person's credentials, private data
  or sensitive logs;
- report security issues through the process in `SECURITY.md`;
- avoid intentionally misleading users with unofficial APKs presented as
  official InSave releases;
- respect software licenses, attribution requirements and the InSave trademark
  and branding policy.

Maintainers may edit, hide, lock or remove contributions that expose secrets,
contain spam, impersonate official releases, create legal/security risk or make
productive technical collaboration impossible.

Good-faith disagreement about architecture, product scope, licensing or QA is
welcome when it remains evidence-based and respectful.
